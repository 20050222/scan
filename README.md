# 文档扫描系统

# 🖨️ 基于 OpenCV 的智能文档扫描系统

**一款基于传统机器视觉算法实现的文档矫正、图像增强、黑白扫描电子化工具**

本项目基于 Python \+ OpenCV 开发，实现**手机拍摄倾斜文档 → 自动四边检测 → 透视矫正拉直 → 图像增强降噪 → 标准黑白扫描件输出**的完整流程。无需深度学习、无需训练模型，纯传统 CV 算法实现轻量、快速、稳定的文档扫描功能。

---

## 📌 项目简介（About）

日常生活中，手机拍摄纸质文件普遍存在**透视倾斜、角度偏移、光照不均、背景杂乱、文字对比度低**等问题，直接拍照存档效果差、不适合打印与电子化归档。

本项目设计并实现了一套**全自动文档扫描图像处理系统**，通过边缘检测、轮廓提取、四边形拟合、四点透视变换、自适应阈值二值化、形态学降噪等计算机视觉技术，能够自动识别纸张边界、矫正几何畸变、优化图像画质，最终生成高清晰度、标准纯白背景的黑白扫描电子文档。

系统全程自动化，无需手动框选顶点、无需手动裁图，输入任意角度拍摄的文档照片，即可输出媲美扫描仪的标准扫描结果。

---

## ✨ 核心功能亮点

- **自动纸张边缘检测**：基于 Canny 边缘检测算法，精准提取文档外轮廓边缘

- **智能四边形筛选**：自动筛选画面最大四边形，精准定位纸质文档区域

- **四点坐标自动排序**：解决轮廓点乱序问题，稳定输出左上、右上、右下、左下标准坐标

- **透视几何矫正**：将倾斜、透视畸变的梯形文档矫正为标准矩形

- **光照自适应二值化**：采用自适应高斯阈值，完美解决手机拍摄光影不均、阴影、偏色问题

- **图像对比度增强**：CLAHE 局部直方图均衡化，强化文字细节、弱化背景干扰

- **形态学智能降噪**：开闭运算组合，去除照片颗粒噪点、雪花斑点，保留文字笔画完整性

- **全流程可视化输出**：支持输出边缘图、轮廓标记图、矫正彩图、最终扫描图多阶段结果

## 📚 算法原理与系统流程

本项目整体分为 **五大核心处理阶段**，层层递进完成文档扫描：

### 阶段一：图像预处理降噪

读取原图 → 等比例缩放加速运算 → 灰度化 → 高斯模糊降噪，消除拍摄噪点，为边缘检测提供干净图像。

### 阶段二：Canny 边缘检测

通过双阈值边缘检测，提取图像所有物体轮廓边缘，精准分离纸张与背景区域。

### 阶段三：轮廓提取与四边形拟合

查找全部轮廓 → 按面积筛选最大轮廓 → 多边形近似拟合，筛选出唯一文档四边形轮廓，定位纸张四个角点。

### 阶段四：四点透视变换矫正

对乱序四点自动排序，计算文档真实宽高，生成透视变换矩阵，矫正透视畸变，将倾斜梯形文档拉直为标准矩形。

### 阶段五：图像增强与二值化降噪

矫正后图像灰度增强 → 自适应阈值二值化 → 形态学开闭运算降噪，最终生成白底黑字、干净高清的标准扫描件。

## 🚀 使用方法

将待扫描图片放入项目目录，终端执行：

```Plain Text
python scan_new.py -i test.jpg
```

程序会依次弹出：原图、边缘图、轮廓检测图、最终扫描对比图，**按任意键切换下一步**。

运行结束自动生成：

- `scan.jpg` —— 最终成品黑白扫描文档

- 多阶段中间过程效果图（便于调试与报告展示）

## 💡 项目优化点（核心亮点，可写进报告）

- **兼容 OpenCV5\.x 新版本**：修复高版本 findContours 返回值兼容问题，全网老旧代码普遍存在此 bug

- **增加文件读取容错机制**：判断图片是否读取成功、判断轮廓是否为空、判断是否检测到四边形，避免程序崩溃

- **自适应阈值替代固定阈值**：彻底解决光照不均、阴影、曝光问题，适配所有拍摄环境

- **CLAHE 对比度增强**：强化浅色文字、提升文档清晰度

- **形态学组合降噪**：开运算去噪点、闭运算补文字断笔，兼顾干净度与文字完整性

- **精准四点排序算法**：杜绝角点错乱导致的图像扭曲、翻转、拉伸问题

## ⚠️ 项目局限性与未来改进方向（报告专用）

### 局限性

- 算法依赖清晰的纸张四边轮廓，若纸张边角遮挡、卷曲、褶皱严重，识别精度下降

- 传统 Canny 阈值为人工设定，无法自适应所有极端光线场景

- 复杂背景、与纸张颜色高度相近的环境容易干扰轮廓检测

### 未来改进方向

- 增加轮廓长宽比、面积筛选逻辑，过滤干扰轮廓

- 设计动态自适应 Canny 阈值，实现全场景自动调参

- 引入深度学习角点检测（CNN/U\-Net），摆脱传统算法依赖边缘的限制

- 增加自动裁剪、水印去除、色彩还原、PDF 批量导出功能
